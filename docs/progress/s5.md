# S5 — widgety i ekrany (progress)

Branch: `claude/s5-features-5e6481`. Katalog: `apps/yoga/src/features/**` (bez `media/`, `map/`). Dziennik pracy; aktualizować po każdym kroku.

## Struktura
- `units/` — formatery (`format.ts`, czyste) + `useUnits()`.
- `_shared/` — `FastNumeric`/`FastGauge`/`FastBar` (imperatywnie, bez re-renderu), `Bar`, `Stat`, `CardTitle`; `actions.tsx` — `ActionButton` (active z telemetrii, pending, optymizm, hold, wyszarzenie), `fastActive`/`slowActive`/`availability`; `features.css` (prefiks `ft-`).
- `gauges/` — widgety `speed` (z rimem overspeed), `rpm`, `fuel`, `cruise`, `rest`, `status`.
- `lights/` — widget `lights`, `LightsModeControl`, `BlinkerArrow` (pulsowanie z `lights.blinker*On`).
- `navigation/` — widgety `nav`, `job`; ekran `nav` (MVP bez mapy).
- `drive/` — ekran `drive`. `vehicle/` — ekran `vehicle` (wszystkie 51 akcji + 3 segmenty `set`). `trip/` — ekran `trip` (trip A, reset z potwierdzeniem).
- `radio/` — `InGameRadioControls` (eksport dla S6) + widget `radio`.
- `alerts/` — `ALERT_PRESENTERS: Record<AlertCode, …>` (kompletność wymusza kompilator) + `EVENT_PRESENTERS` (dostawa, zlecenie, mandat, myto, prom, pociąg, tankowanie, naczepa).
- `_dev/` — diagnostyka (surowe akcje); widget `speed` z F0 usunięty.
- `test/` — Vitest (units, widgety, alerty, panel pojazdu na prawdziwym bridge'u + MockSource).

- M2: ekran `vehicle` — każda akcja z `ACTIONS` jako przycisk z `active` z telemetrii, `pending`, optymizmem i rollbackiem (CommandBus), hold, wyszarzeniem (`inputEnabled=false`, `not_supported`, `verified:false`).
- M3: alerty (15 kodów) i eventy, `trip`, sekcja „Radio w grze” (ekran vehicle + kafel `radio`).
- Testy: 149 w `features/test` (formatery tabelarycznie, brak danych/null we wszystkich widgetach i ekranach, test braku re-renderów przy `fast.speed/rpm` przez Profiler, presentery po `AlertCode`, 51 akcji → poprawny `cmd` + ack ok na prawdziwym bridge'u z mockiem, stan przycisku po ack, rollback `ok:false`, `not_supported`).
- Weryfikacja ręczna na mocku (bridge 7428, Vite 5176, 1280×800): Home, drive, nav, vehicle, trip, toasty alertów, rim overspeed. Scenariusze przejrzane wzrokowo: `highway`, `low-fuel`, `job-cycle`.

- Profil React DevTools na Yodze (w testach Profiler potwierdza 0 commitów przy zmianach `fast`).
- Pomiar p95 klatek na Yodze (S3/S7).
