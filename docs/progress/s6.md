# Postęp S6 (media)

## Zrobione
- Spike S6-0: PowerShell/WinRT zamiast `windows-smtc-monitor` (bez zależności, bez kompilacji), wyniki w `integrations/media/SPIKE.md`.
- `integrations/media`: `bin/smtc.ps1` (helper JSON-lines), `helper-protocol.ts` (parser + mapowanie `MediaState`),
  `smtc.ts` (`SmtcMediaProvider`: auto-restart z backoffem, komendy z ack/timeout, cache okładek w pamięci),
  `factory.ts` (`AutoMediaProvider`/`createMediaProvider`: SMTC → fallback `NullMediaProvider`, `start()` nie rzuca),
  `mock.ts` (Mock rozbudowany: 4 utwory, okładki SVG przez `getArt`).
- Testy: `integrations/media/src/smtc.test.ts` (23): parser, mapowanie, restart, poddanie się, timeouty, fallback.

## Zostało
- UI (`apps/yoga/src/features/media/`), propozycja podpięcia w bridge (`docs/proposals/s6-bridge-wiring.md`), README, weryfikacja przepływu.
